# جذر الثقة والسيادة الرقمية

هذه أول نواة تنفيذية للدولة: هوية الملك، سلطة الشهادات، هويات الوكلاء، سجل أحداث مقاوم للعبث، وبوابة التاج.
الأوامر الملكية موقعة بـ Ed25519، وتُرفض عند تغيير محتواها أو غياب التوقيع الصحيح.
كل حدث يملك تجزئة وسابقة؛ أي تعديل يكسر سلسلة التدقيق ويُكتشف عند التحقق.
النقض والإيقاف يعملان قبل تنفيذ الأمر، ولا يُفتح الاستئناف إلا بقرار ملكي جديد.
هذه نواة محلية أولية؛ قبل الإنتاج يجب إضافة تخزين دائم، إدارة مفاتيح مادية، ومراجعة أمنية مستقلة.

تمت إضافة حماية إعادة تشغيل الأوامر وانتهاء صلاحيتها، ومحرك صلاحيات أولي، وسجل أحداث دائم بصيغة JSONL مع تحقق من سلسلة التجزئة.

## تقوية P0 الإضافية
- سجل أوامر دائم يمنع إعادة تنفيذ الأمر حتى بعد إعادة تشغيل العملية.
- مخزن مفاتيح محلي مشفر كطبقة تجريد؛ لا يُعد بديلًا عن HSM/KMS الإنتاجي.
- ربط محرك الصلاحيات ببوابة التاج للأفعال الحساسة.
