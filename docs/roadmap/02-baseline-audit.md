# 2 — تدقيق خط الأساس: الحالة الحقيقية بالأدلة

**تاريخ التدقيق:** 2026-08-23. **المرجع:** الفرع `main`، شجرة Git كاملة (‏33,436 ملفاً / 3,528 مجلداً / ‏16.1 ميجابايت).
**المنهج:** لم يُفترض صحة أي وثيقة قائمة. جُلبت شجرة Git الكاملة، ونُزّلت الملفات الجوهرية وقُرئت، وشُغّلت الاختبارات فعلياً، وقُوبل كل رقم معلَن بعدّ آلي مستقل.

هذه الوثيقة هي **المرجع الوحيد للحالة**. عند التعارض بينها وبين أي ملف آخر، تُقدَّم هذه الوثيقة، ويُصحَّح الآخر.

## 2.1 الحكم المختصر

المستودع في حالته الراهنة هو **هيكل تنظيمي ضخم مولَّد آلياً**، بداخله **نواة سيادية صغيرة حقيقية تعمل وتُختبر**. لا يوجد بينهما جسر: النواة لا تقرأ الهيكل، والهيكل لا يستدعي النواة.

- **يعمل فعلاً:** عشرة ملفات `.mjs` تحت `src/`، و27 اختباراً ناجحاً.
- **قائم اسماً فقط:** 6,891 ملف TypeScript، و13,278 ملف YAML، و262 ملف SQL — بلا مُصرِّف ولا قارئ ولا مُنفِّذ.
- **الحجم مُضلِّل:** متوسط حجم الملف **482 بايت**، و**23 ملفاً فقط** من أصل 33,436 يتجاوز 1,500 بايت.
- **نسبة الإنجاز المحقّقة مقابل تعريف 100%:** ‏**≈ 4%** يوم التدقيق (خط الأساس). **النسبة المعتمدة الآن: ≈ 96%** بعد `M0` (‏8/9) و`M1` و**المسارات `M2` و`M3` و`M4` و`M5` و`M6` و`M7` و`M8` كاملةً** و**المسار `M9` كاملاً** (‏7/7) و**المسار `M10` كاملاً** (‏9/9) (والبوابات `G2` و`G4` و`G5` و`G6` و`G8` مفتوحة بتحفّظات معلنة، و`G9` تُعَدّ مفتوحةً بتحفّظاتٍ معلَنةٍ وقرارُ إغلاقِها محجوزٌ للمالك، و`G10` لم تُفتَح بعدُ رغم اكتمالِ خطواتِ `M10`، **وقد فُتِحت لاحقاً بقرارٍ سياديٍّ في `WL-065` لغرضِ بدءِ `M11` وحدَه، وصارَ `M11 = 3/9` في `WL-067` ثم `4/9` في `WL-068` بإغلاقِ `M11.07` ثم `5/9` في `WL-069` بإغلاقِ `M11.08` — لا `G11` ولا إطلاقٌ**) (كان مكتوباً «≈16%» ثم «≈26%» ثم «≈94%» وكلاها إما متأخرٌ عن صفوف §2.9.1 أو مُشتقٌّ من ثابتٍ محمولٍ لا يُشتَقُّ من الجدولِ — **ومنذُ `WL-063` تُحسَبُ النسبةُ آلياً من عدّادِ الخطواتِ بالصيغةِ المعمّمةِ**، وآخر تحديثٍ في `WL-076`) — انظر §2.9.1. وتصحيحات هذه الوثيقة نفسها في §2.10.

|---|---|
| `identity.mjs` | هوية الملك بـ Ed25519، سلطة شهادات تُصدر هويات وكلاء وتتحقق منها، بصمة مفتاح |
| `crown.mjs` | بوابة التاج: تحقّق توقيع، منع إعادة الإرسال، انتهاء صلاحية، تحمّل انزياح الساعة، خطّاف سياسة، إيقاف طارئ واستئناف، و`createRoyalCommand` |
| `event-log.mjs` | سجل أحداث مرتبط بالتجزئة، يكتشف العبث |

| `anchor.mjs` | تثبيت دوري موقَّع ملكياً في مخزن منفصل، يكشف تعديل حدث قديم (‏`WL-010`) |

| `halt-switch.mjs` | إيقاف شامل: توجيه موقَّع دائم بعصرٍ لا يتراجع، وتأكيد إيقاف من كل عقدة، وفشل مُغلَق (‏`WL-012`) |
| `clock.mjs` | ساعة تكشف انزياحها: مقايسة ساعة الحائط على عدّاد رتيب، وحدٌّ أعلى ذري على القرص يكشف الرجوع بين تشغيلين، وإبطالٌ لاصق لا يُشفى إلا بشهادة صريحة (‏`WL-013`) |
| `policy.mjs` | محرّك سياسة مبدئي بمجموعة أفعال حسّاسة |
