# 1 — تعريف المشروع

**الحالة:** معتمدة كمرجع للتعريف. **الإصدار:** 1.0.0. **التاريخ:** 2026-08-23.

هذه الوثيقة تُجيب على سؤال واحد: **ما هذا المشروع؟** وهي مكتوبة من الصفر بعد قراءة المستودع كاملاً، ولا تفترض صحة أي وصف سابق. الحقيقة الوحيدة المسلَّم بها ابتداءً هي المعطى الذي أقرّه مالك المشروع: أن هذا **دولة ملكية فدرالية رقمية تدير وتشغّل عالم الذكاء الاصطناعي — وكلاء ونماذج وبيئة — كعالم رقمي**. كل ما دون ذلك مبنيّ على استنباط موثّق من محتوى المستودع.

---

## 1.1 الجملة الواحدة

منظومة برمجية سيادية تُنشئ وتُدير **عالماً رقمياً مأهولاً بوكلاء ذكاء اصطناعي**، ينتظمون في مؤسسات وأقاليم وولايات وبلديات، تحكمهم قوانين وسياسات قابلة للتنفيذ الآلي، وتُقيّد كل قرار مؤثر ببوابة سلطة واحدة (**التاج**) تخضع لإنسان واحد (**الملك**)، مع سجل تدقيق غير قابل للعبث وإمكانية إيقاف شامل في أي لحظة.

## 1.2 المشكلة التي يحلّها

عندما يتحرك عدد كبير من الوكلاء المستقلين داخل بيئة واحدة، تظهر خمس مشكلات لا تحلّها أدوات التشغيل التقليدية:

1. **الهوية:** من هذا الوكيل، ومن أصدره، وهل يمكن انتحاله؟
2. **الصلاحية:** ما يحقّ له فعله بالضبط، ومن يمنحه ذلك، ومتى يُسحب؟
3. **المساءلة:** ما الذي حدث فعلاً، ومن أمر به، وهل يمكن العبث بالسجل؟
4. **السيطرة:** كيف يُوقَف كل شيء فوراً عند الخطأ، ثم يُستعاد بأمان؟
5. **التوسّع المنظّم:** كيف يكبر العالم من عشرة وكلاء إلى ملايين دون أن يفقد الحكم قدرته على الرؤية والمنع؟

الحل المعماري المطروح هنا هو نقل نموذج **الدولة** — دستور، قانون، قضاء، مؤسسات، أقاليم، ميزانيات، سجلات مدنية — إلى طبقة البرمجيات، بحيث تصبح الحوكمة خصيصةً تقنية قابلة للاختبار، لا سياسةً مكتوبة على الورق.

## 1.3 المبادئ الحاكمة (غير قابلة للتفاوض)

| # | المبدأ | ما يعنيه تنفيذياً |
|---|---|---|
| P1 | **سلطة بشرية عليا** | لا قرار سيادي يُنفَّذ دون أمر ملكي موقّع تشفيرياً ويمرّ ببوابة التاج |
| P2 | **أقل امتياز** | كل وكيل يبدأ بصفر صلاحيات؛ كل صلاحية تُمنح صراحةً ومؤقتاً ومُدقَّقة |
| P3 | **سجل غير قابل للعبث** | كل حدث ذي أثر يُسجَّل في سلسلة مرتبطة بالتجزئة، وأي عبث يُكتشف |
| P4 | **إيقاف شامل مضمون** | زر إيقاف واحد يجمّد كل تنفيذ في كل مكان، ويُختبر دورياً |
| P5 | **لا استقلالية بلا احتواء** | لا تُمنح قدرة للوكيل قبل توفّر عزلها ومراقبتها والتراجع عنها |
| P6 | **الحكم قابل للتدقيق** | كل سياسة وقانون يُقرأ ويُقيَّم آلياً، ويُمكن إثبات سبب أي قرار |
| P7 | **الفدرالية بالتفويض** | الأقاليم تعمل باستقلال تشغيلي داخل حدود صلاحيات مفوّضة قابلة للسحب |
| P8 | **الإنجاز يُقاس بالاختبار** | لا يُعدّ شيء موجوداً حتى يُشغَّل ويُختبر (وهي المادة 2 من القاعدة الحاكمة) |

## 1.5 المفردات المعتمدة

| المصطلح | التعريف التنفيذي الدقيق |
|---|---|
| **الملك** | صاحب المفتاح الخاص الجذري الوحيد (Ed25519). سلطة بشرية، لا كياناً برمجياً |
| **التاج (Crown)** | البوابة البرمجية التي تتحقق من توقيع الأمر الملكي وصلاحيته ونضارته قبل تنفيذ أي فعل حسّاس |
| **الأمر الملكي** | حِزمة موقّعة تحمل: الفعل، الهدف، وقت الإصدار، وقت الانتهاء، معرّف فريد لمنع الإعادة |
| **حق النقض (Veto)** | قدرة إيقاف فعل قبل تنفيذه أو تجميد المنظومة كلها |
| **الوكيل (Agent)** | كيان تنفيذي له هوية مُشهّدة، وحصص محددة، وقدرات مُصرَّح بها اسماً |
| **النموذج (Model)** | أوزان ذكاء اصطناعي بمعرّف وبصمة تجزئة، تُنشَّط لغرض معلَن وتُسحب بالتراجع |
| **المجال (Domain)** | وحدة تخصص (125 مجالاً) بست طبقات ثابتة: حوكمة، تشغيل، تعليم، بحث، سجل، سلامة |
| **المؤسسة** | كيان له اختصاص وصلاحيات وميزانية ومساءلة (143 مؤسسة معرَّفة اسماً) |
| **الإقليم / الولاية / البلدية** | التقسيم الفدرالي الإداري: 16 → 256 → 1536 |
| **القانون** | نص قابل للتقييم الآلي، لا يُنفَّذ إلا باعتماد التاج، وله حالات صريحة |
| **المحكمة** | مسار فصل النزاعات: قضية → جلسة → حكم مُسبَّب → استئناف |
| **السياسة (Policy)** | قاعدة قابلة للتقييم قبل التنفيذ، تُصنّف الأفعال إلى مسموح/حسّاس/محرّم |
| **الحصة (Quota)** | حد أعلى قابل للقياس على استهلاك الوكيل للحساب أو البيانات أو الميزانية |
| **العتبة السيادية** | مجموعة الأفعال التي لا تنفَّذ أبداً دون أمر ملكي |

## 1.6 حدود المشروع

**داخل النطاق:** الحوكمة، الهوية، الصلاحيات، التدقيق، السيطرة، تنظيم الوكلاء والنماذج، إدارة البيانات والذاكرة، المؤسسات والفدرالية، الواجهات السيادية، الاستمرارية والتعافي.

**خارج النطاق صراحةً:** تدريب نماذج أساس من الصفر، بناء عتاد فيزيائي، أي ادعاء بسيادة قانونية على أرض أو بشر، أي تعامل مع عملات أو أصول مالية حقيقية. مصطلحات مثل «الطاقة» و«الميزانية» و«السكان» تعني **حصصاً وموارد حسابية داخلية**، لا مقابلات فيزيائية أو مالية حقيقية.

**تنبيه على الأرقام:** الأعداد الواردة (125 مجالاً، 143 مؤسسة، 1536 بلدية، أعداد السكان) هي **سعات وحصص هيكلية مخطَّطة**، وليست كيانات مُشغَّلة. لا يجوز عرضها كإنجاز. راجع الوثيقة 02.

## 1.7 البيئة التقنية المستهدفة

| البند | القرار | المبرر |
|---|---|---|
| زمن التشغيل | Node.js 20 LTS، ESM حصراً | ما يعمل عليه الكود القائم فعلياً |
| لغة الخدمات | TypeScript صارم (`strict: true`) | 6,891 ملف `.ts` قائم اسماً؛ ويجب أن يُصبح حقيقياً |
| النواة السيادية | JavaScript/TypeScript بأقل تبعيات ممكنة | تقليل سطح الهجوم في جذر الثقة |
| التشفير | `node:crypto` — Ed25519 للتوقيع، AES-256-GCM للتخزين، scrypt للاشتقاق | قائم فعلاً في `src/root-of-trust/` |
| الاستمرارية | PostgreSQL + هجرات مُرقَّمة | لا شيء اليوم يصمد بعد إعادة التشغيل |
| المفاتيح | مخزن أسرار خارجي / HSM؛ لا مفاتيح في المستودع أبداً | أولوية P0 معلَنة في `docs/REMAINING_WORK.md` |
| السياسات والقوانين | YAML كبيانات تُقرأ وتُتحقَّق بمخطَّط | لا تُترك تعليقات نصية بلا قارئ |
| الاختبار | `node:test` للنواة + إطار موحّد للخدمات | 27 اختباراً ناجحاً قائم بالفعل |
| التكامل المستمر | GitHub Actions | لا وجود له حالياً — فجوة حرجة |

## 1.8 ما يعنيه «يعمل بكامل قوته»

المنظومة تعمل بكامل قوتها عندما تتحقق الجُمل التالية كلها، كل واحدة بدليل قابل للتشغيل:

1. يستطيع الملك إصدار أمر موقّع من واجهة، ويُنفَّذ، ويظهر في سجل تدقيق يصمد بعد إعادة التشغيل ويُكتشف أي عبث فيه.
2. لا يستطيع أي وكيل فعل شيء لم يُصرَّح به اسماً، والمنع يُثبَت باختبار محاولة اختراق.
3. مؤسستان حقيقيتان على الأقل تعملان فعلياً: تستقبلان مهاماً، تنفّذانها بوكلاء، تستهلكان ميزانية محدودة، وتُنتجان تقارير.
4. إقليم واحد على الأقل يعمل معزولاً بصلاحيات مفوَّضة، وسحب التفويض يُوقفه فوراً.
5. زر الإيقاف الشامل يُجرَّب دورياً ويُثبت أنه يجمّد كل تنفيذ، والاستعادة تعيد الحالة كاملة.
6. توجد نسخ احتياطية مُختبرة باستعادة فعلية وزمن تعافٍ معلَن ومُقاس.
7. توجد مراقبة تُظهر الصحة والتكلفة والسعة، وتنبيهات مربوطة بمسار حوادث مكتوب ومُجرَّب.
8. جرت مراجعة أمنية مستقلة واختبار اختراق، وأُغلقت النتائج الحرجة.
9. كل نطاق معلَن في الوثائق إما مُنفَّذ ومختبر، أو مُعلَن صراحةً كمؤجَّل — لا منطقة رمادية.
10. صدر قرار جاهزية موقّع من الملك بناءً على تقرير تدقيق، وسُجّل في سجل الأحداث.
