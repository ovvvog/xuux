## 1 — قواعدُ العزل (‏إلزاميّة)

- اعملْ **فقط** داخلَ مجلّدِك: `/home/user/council/<member-id>/` (‏يُعطى لك في رسالةِ التكليف).
- **ممنوعٌ** قراءةُ أيِّ مجلّدٍ آخرَ تحتَ `/home/user/council/` غيرِ مجلّدِك وهذا الملفّ، وممنوعٌ قراءةُ `/home/user/workspace/` (‏شجرةُ المنفِّذ).
- لا تكتبْ تقريرَك على القرص خارجَ مجلّدِك. **سلِّمْ تقريرَك النهائيَّ كاملاً في رسالةٍ إلى `/root` وحدَه**، ولا تراسلْ أيَّ وكيلٍ آخر.
- استنسخِ المستودعَ بنفسك: `git clone https://github.com/ovvvog/xuux.git repo && cd repo && git checkout fcb379ca`.
  لا تقرأْ تعليقاتِ المراجعةِ على طلباتِ GitHub قبلَ أن تُكوِّنَ حكمَك (‏يمكنك قراءةُ وصفِ الطلبِ والكوميتات).
- قاعدةُ بيانات: PostgreSQL 18.7 مثبَّتٌ في `/usr/lib/postgresql/18/bin`. **أنشئْ عنقودَك الخاصَّ** على المنفذِ المعطى لك:
  ```
  B=/usr/lib/postgresql/18/bin; D=$PWD/pgdata; $B/initdb -D $D -U state --auth=trust >/dev/null
  $B/pg_ctl -D $D -o "-p <PORT> -k $D -c listen_addresses=127.0.0.1" -l $D/log start
  $B/psql -h 127.0.0.1 -p <PORT> -U state -d postgres -c "ALTER ROLE state PASSWORD 'state'" -c "CREATE DATABASE state"
  export DATABASE_URL=postgresql://state:state@127.0.0.1:<PORT>/state PATH=$B:$PATH
  npm ci && npm run build && npm run migrate -- up
  ```
  وأوقفْه في النهاية (‏`pg_ctl -D $D stop`). الجهازُ مشترَكٌ بمعالجَين: **شغّلِ الاختباراتِ المستهدَفةَ لا `npm test` كاملاً**
  (‏مثلاً `node --test --test-concurrency=1 --test-timeout=120000 <file>`). بطءٌ أو مهلةٌ تحتَ الحملِ ليست عيباً ما لم تُثبِتْ سببَها.
