# الدستور — التصميم والضمانات والحدود المعلَنة

**الخطوة:** `M8.01` · **المُدخلة:** `WL-033` · **البوابة:** `guard:constitution` (الثامنة عشرة في `npm run validate`).

هذه الوثيقة تشرح **لماذا** بُني الدستور على هذا النحو، و**ما يضمنه فعلاً**، و**ما لا يضمنه**. أمّا نصُّ الموادّ فموضعه [`../constitution/README.md`](../constitution/README.md) و[`../constitution/ARTICLES.md`](../constitution/ARTICLES.md)، ومصدرُ الحقيقة الوحيد هو [`../config/constitution.yaml`](../config/constitution.yaml).

## 1. العيب المقيس الذي أُغلق

لم يكن في المستودع دستورٌ بأيّ معنى. والأخطرُ ممّا يبدو: **إحدى وعشرون قاعدةً في `config/` كانت تحمل حقلَ `lawRef` يُشير إلى ثمانيةِ مراجعِ قانونٍ لا وجودَ لها** — `law:legislation` · `law:root-of-trust` · `law:sovereign-halt` · `law:policy-governance` · `law:data-sovereignty` · `law:retention` · `law:agent-registry` · `law:public-finance`. كانت سلاسلَ نصٍّ **لا يقرؤها كودٌ ولا يقيسها حاجز**: زخرفةٌ تُوهم القارئَ أنّ للقواعد سنداً قانونياً.

وكان تعديلُ **أعلى نصٍّ** في `src/state/law-registry.mjs` نداءَين متتاليَين من فاعلٍ واحد (`enact` ثم `repeal`) بلا مراجعةٍ ولا مهلةٍ ولا ختمِ مادّة، وسلطةُ التاج فيه **سلسلةَ نصٍّ** تُمرَّر في وسيطٍ لا شهادةً موقَّعة.

## 2. أربع طبقات

| الطبقة | الملف | ما تضمنه |
|---|---|---|
| النصّ | `config/constitution.yaml` + مخطَّطُه الصارم | كلُّ مادّةٍ لها معرّفٌ ومرجعُ قانونٍ ونصٌّ ومواضعُ إنفاذٍ وحالةُ ختم؛ ولا حقلَ زائداً (`additionalProperties: false`) |
| المخزن | `src/constitution/constitution.mjs` | ختمُ النصّ المؤسِّس، وسلسلةُ عهودٍ موقَّعة، وعدّادُ عهدٍ لا يتراجع، وكتابةٌ ذرّية |
| المسار | `src/constitution/amendment-path.mjs` | أربعُ خطواتٍ بفاعلين مختلفين ومهلةٍ مقيسة، وكلُّ رفضٍ حادثةٌ مسجَّلة |
| الحاجز | `scripts/guard-constitution.mjs` | يُسقط `npm run validate` إن انحرف الإعلانُ عن الواقع |

## 3. الضمانات — وكلٌّ منها رمزُ رفضٍ يقع فعلاً

**القاعدةُ التي بُنيت عليها السياسة:** بندُ ضمانٍ بلا رمزِ رفضٍ نصٌّ حرّ، ورمزُ رفضٍ بلا بندٍ رفضٌ بلا سند. فكلُّ بندٍ في `guarantees` يحمل `code` و`enforcedBy`، **والحاجزُ يقرأ وحدةَ الإنفاذ ويشترط حضورَ الرمز فيها**.

| الرمز | ما يمنعه |
|---|---|
| `CONSTITUTION_FOUNDING_TEXT_DRIFT` | تحريرُ `config/constitution.yaml` بعد ختمِ العهد الأول — **يُعطِّل قراءةَ الدستور** لا يُحذّر |
| `CONSTITUTION_TAMPERED` | كسرُ حلقةٍ في سلسلة العهود أو توقيعٌ لا يُتحقَّق بمفتاح الملك |
| `CONSTITUTION_EPOCH_ROLLBACK` | حذفُ عهدٍ من الملفّ — يُكشف بعدّادِ أعلى عهدٍ بُلغ، وهو ما **تسكت عنه سلسلةُ التجزئةِ وحدَها** لأنّ سلسلةً مقتطعةً متّصلةٌ في نفسها |
| `CONSTITUTION_ARTICLE_ENTRENCHED` | المسُّ بمادّةٍ مختومةٍ ولو استُوفي المسارُ كاملاً |
| `CONSTITUTION_ARTICLE_UNKNOWN` | تعديلُ مادّةٍ غيرِ موجودة |
| `CONSTITUTION_STORAGE_INVALID` | مخزنٌ لا يُقرأ أو سلسلةٌ خالية — **فشلٌ مغلقٌ** لا قراءةُ فراغ |
| `AMENDMENT_NOT_ROYAL` | تعديلٌ بلا أمرٍ ملكيٍّ مقبولٍ عبر بوابة التاج |
| `AMENDMENT_WRONG_ACTION` | أمرٌ ملكيٌّ بفعلٍ غير `amend-constitution` / `ratify-constitution` |
| `AMENDMENT_SELF_REVIEW` | مراجعةُ المرءِ طرحَه |
| `AMENDMENT_REVIEWER_ROLE` | مراجعةٌ من غير رئيس القضاة |
| `AMENDMENT_NOT_REVIEWED` | إبرامٌ قبل المراجعة |
| `AMENDMENT_DELIBERATION_PENDING` | إبرامٌ قبل انقضاء مهلة التدبُّر |
| `AMENDMENT_HASH_MISMATCH` | إبرامُ غيرِ ما طُرح وروجع |
| `AMENDMENT_REASON_TOO_SHORT` | طرحٌ بلا سببٍ مكتوب |

## 4. المسار الرباعي — ولماذا أربعٌ لا واحدة

```
  ┌──────────┐   أمرٌ ملكيّ    ┌──────────┐  رئيسُ القضاة  ┌────────────┐
  │  طَرْحٌ    │ ─────────────▶ │ مراجعةٌ   │ ─────────────▶ │  تدبُّرٌ     │
  └──────────┘  amend-…       └──────────┘   رأيٌ مكتوب   └────────────┘
                                                                 │ 604800 ثانية
                                                                 ▼
                                                          ┌────────────┐
                                                          │  إبرامٌ     │  أمرٌ ملكيٌّ ثانٍ
                                                          └────────────┘  ratify-… + تجزئةُ الطرح
```

**لماذا الساعةُ تُمرَّر؟** لأن مهلةً تُقاس على `Date.now()` مدفونةٍ في الدالّة **لا تُختبر إلا بانتظار أسبوع**، فتبقى دعوىً. تمريرُ الساعة في المُنشئ يجعل المهلةَ **مقيسةً في اختبارٍ يُشغَّل في ثوانٍ**.

**لماذا تجزئةُ الطرح في أمر الإبرام؟** كي لا يُبرَم غيرُ ما طُرح وروجع: بدونها تصير المراجعةُ ختماً على ورقةٍ بيضاء.

## 5. حدود معلَنة — ما لا تضمنه هذه الخطوة

1. **المخزنُ ملفٌّ ذرّيٌّ لا جدولُ PostgreSQL** — بقصدٍ: الدستورُ يُقرأ قبل أن توجد قاعدة، ولا يجوز أن يتوقّف أعلى نصٍّ على خدمةٍ قد لا تعمل. والأثرُ أنّ لا قيدَ قاعدةٍ يحرس السلسلة.
2. **العبثُ يُكشف ولا يُمنع** — من ملك القرصَ **ومفتاحَ الملك** يكتب عهداً صحيحاً. المنعُ يلزمه مخزنُ أجهزةٍ أو مُطلِقٌ في قاعدة، ولم يُكتب ما لم يُشغَّل.
3. **الطروحُ غيرُ المُبرَمة في الذاكرة** — تزول بإعادة التشغيل ولا تُستأنف مهلةُ تدبُّرها.
4. **لا إعادةَ توقيعٍ عند تدوير مفتاح الملك** — التدويرُ يُعطِّل قراءةَ السلسلة: فشلٌ **مغلقٌ** لا صامت، لكنّه توقُّف.
5. **النصُّ يُقاس حضوراً وطولاً وتجزئةً لا معنىً** — لا شيء يمنع مادّةً نصُّها ركيك.
6. **المرجعُ يُسنَد ولا يُنفَّذ** — القاعدةُ R4 تضمن أنّ لكلِّ `lawRef` مادّةً قائمة، **لا** أنّ القاعدةَ المستندةَ إليه تطبّق ما تقوله المادّة. وذاك نصُّ `M8.02`.
7. **`LawRegistry` غيرُ موصولٍ بالدستور** بعد، **وقضايا المحكمة ما زالت في الذاكرة** (تحفّظُ G3) — موضعُهما `M8.02` و`M8.03`.
