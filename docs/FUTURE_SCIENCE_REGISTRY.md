# سجل العلوم المستقبلية والافتراضية

المجال: بحث طويل الأفق مع بوابة أخلاق وسلامة ومراجعة بشرية.
المخرجات: فرضيات ونماذج ومحاكاة وتجارب معزولة وتقارير قابلة للتكرار.
الحد: لا ينتقل البحث إلى التشغيل أو العالم الخارجي دون اعتماد مستقل.
