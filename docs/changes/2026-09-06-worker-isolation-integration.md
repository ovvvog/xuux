# دفعة دمج العزل التنفيذي بالعامل

## ما تغيّر

أصبح سكربت العامل الإنتاجي يركّب `PersistentEventLog` ويمرّر إعداد العزل الحقيقي إلى `createWorker`. عند تفعيل العامل، تُنفّذ المهمة عبر `unshare` و`chroot` وnamespaces user/mount/network/pid، مع runtime Node واحد مربوط للقراءة فقط، وworkdir للقراءة فقط، ومجلد output صريح للكتابة. لا توجد عودة صامتة إلى `runWithLimits` داخل مسار العامل الإنتاجي؛ المسار القديم يبقى متاحاً فقط عندما لا تُمرّر تهيئة العزل إلى الوحدات الاختبارية.

أضيف `scripts/isolated-task-runner.mjs` ليستقبل action وpayload كنص JSON ويعيد غلاف نتيجة واحداً عبر stdout. هذا يزيل الاعتماد على IPC داخل chroot، ويُبقي سجل المعالجات ثابتاً داخل الكود. كما أضيف دعم `AbortSignal` إلى منفّذ العزل؛ عند فقد العقد أو طلب الإلغاء تُقتل مجموعة العملية المعزولة فعلياً، ويُسجّل `ISOLATION_CANCELLED` بدلاً من إسقاط الإشارة. أُعلن الحدث `isolation.cancelled` في `config/events.yaml` بالحقول `code` و`durationMs` و`signal`، ولذلك بقي حاجز الأحداث قادراً على مطابقة كل موضع نشر.

## الإثبات الاختباري

| الفحص | النتيجة |
|---|---|
| `npm run lint` | ناجح؛ لا أخطاء، مع تحذيرين قديمين عن تعطيل ESLint غير مستخدم |
| اختبار الشبكة داخل namespace | ناجح؛ الهروب مرفوض ومُسجّل |
| الكتابة خارج output | ناجح؛ رفض EROFS/EACCES والحجر يُستدعى |
| الكتابة داخل output | ناجح؛ المسار المعلن وحده قابل للكتابة |
| المهلة | ناجح؛ مجموعة العملية تُقتل |
| حد الذاكرة | ناجح؛ يُميّز عن المهلة |
| isolated-task-runner مع handler فعلي | ناجح داخل العزل الحقيقي |
| تكامل `createWorker` مع العزل الحقيقي | ناجح؛ المهمة تصل إلى `succeed` والنتيجة تعود من handler |
| اختبارات `limits` والإلغاء القديمة | ناجحة |
| اختبارات worker على PostgreSQL عبر Pooler | ناجحة في مسارات الحجز والإيقاف والإلغاء والمهلة |

## حدود معلنة

هذه الدفعة تثبت مسار العزل في المضيف الحالي وCI-like tests، لكنها لا تثبت وحدها cgroups أو محاسبة الذاكرة المقيمة عبر حاويات متعددة، ولا تثبت كارثة متعددة المناطق أو اختراقاً مستقلاً. المراجعة الأمنية واختبار الاختراق الخارجيان يبقيان مطلوبين، كما يبقى ربط الحوادث والحجر بمخزن PostgreSQL الدائم دفعة لاحقة.

## الأمن والنظافة

تُحذف مجلدات output المؤقتة بعد كل تشغيل، وأضيفت قواعد Git تمنع دفعها. لم تُضف مفاتيح أو كلمات مرور أو روابط اتصال إلى المستودع.
