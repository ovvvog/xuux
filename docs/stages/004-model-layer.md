# المرحلة 004 — طبقة النماذج ومحركات الذكاء

## الحالة
مكتملة كنواة محلية أولية للنماذج؛ ليست منصة تدريب أو استدلال إنتاجية.

## المنجز
- سجل نموذج ببيان اسم وإصدار وغرض ومصدر.
- بصمة SHA-256 للأوزان والتحقق من عدم التغيير.
- حصة قصوى للنماذج.
- رفض قدرات تعديل الذات، تجاوز التاج، الكتابة الخارجية، والإنشاء غير المحدود.
- حالات registered وsandboxed وapproved وsuspended وrolled-back.
- تفعيل نموذج واحد لكل غرض مع تسجيل النموذج السابق.
- ساحة معزولة تمنع الشبكة والكتابة.
- منع إعادة نموذج تم التراجع عنه.
- اختبارات البيان والبصمة والسلامة والموافقة والتراجع.

## المتبقي
- مخزن أوزان فعلي وموقع مصدر موثوق.
- تقييم حقيقي للسلامة والدقة والانحياز والهلوسة.
- إدارة موارد GPU وجدولة التدريب.
- تشغيل استدلال معزول بمهلة وإلغاء ومراقبة.
- توقيعات artifacts وسلسلة توريد قابلة للتحقق.
- تراجع موزع ومتسق بين المناطق.
