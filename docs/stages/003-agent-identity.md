# المرحلة 003 — هوية الوكلاء وسجل السكان التشغيلي

## الحالة
مكتملة كنواة محلية أولية، وليست سجل سكان موزعًا جاهزًا للإنتاج.

## المنجز
- سجل وكيل مركزي بحد أقصى قابل للضبط.
- إصدار شهادة مرتبطة بالوكيل والدور والقدرات.
- رفض الصلاحيات السيادية أو تصدير المفاتيح أو تعديل السياسة ذاتيًا.
- حالات active وsuspended وrevoked وretired.
- إلغاء الشهادة عند الإلغاء ومنع إعادة تفعيل الوكيل الملغى.
- تسجيل الإنشاء وتغيرات الحالة في سجل الأحداث.
- اختبارات التسجيل والحصة والصلاحيات والإلغاء.

## المتبقي
- تخزين دائم وموزع لسجل السكان.
- إثبات هوية الجهاز وقياس سلامة بيئة التشغيل.
- مراجعة بشرية للتعيين في الأدوار الحساسة.
- نظام تفويض زمني وحصص موارد لكل وكيل.
- مزامنة الإلغاء بين المناطق دون تأخير خطير.
- تقاعد آمن وحذف الذاكرة وفق سياسة احتفاظ.
