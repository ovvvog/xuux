# جامعة الاقتصاد

النوع: مؤسسة سيادية أو تعليمية أو بحثية أو خدمية ضمن الدولة الرقمية.
الغرض: تقديم اختصاص جامعة الاقتصاد بحدود معلنة وموارد قابلة للقياس.
الهيكل: ميثاق، تنظيم، سير عمل، موارد، موظفون، مرافق، سلامة، مؤشرات، تدقيق، واختبار.
السلطة: لا تتجاوز التفويض؛ القرارات المؤثرة تمر عبر التاج وسجل التدقيق.
الحالة: تعريف مؤسسي تأسيسي قبل التنفيذ المرحلي.
