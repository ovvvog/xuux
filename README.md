# الدولة الملكية الفدرالية الرقمية

منظومة برمجية سيادية تُنشئ وتُدير عالماً رقمياً مأهولاً بوكلاء ذكاء اصطناعي ونماذج، ينتظمون في مؤسسات وأقاليم وولايات وبلديات، تحكمهم قوانين وسياسات قابلة للتنفيذ الآلي، ويُقيَّد كل قرار مؤثر ببوابة سلطة واحدة (**التاج**) تخضع لإنسان واحد (**الملك**)، مع سجل تدقيق غير قابل للعبث وإمكانية إيقاف شامل في أي لحظة.

## الحالة الحقيقية (محقَّقة في 2026-08-23)

- **نسبة الإنجاز:** ‏≈16% من تعريف الـ100% (خط الأساس كان ≈4%). الحساب وسجل التحديثات في [تدقيق خط الأساس §2.9](docs/roadmap/02-baseline-audit.md).
- **المرحلة الحالية:** المسار **M1 — تصفية الحقيقة** مُغلق: ‏8 خطوات من 8 منجزة ومُختبرة، و**البوابة G1 مفتوحة**. الشجرة صارت بيانات في `seed/`، وحُذف **33,271** ملفاً قالبياً (المستودع: 33,456 → **201** ملفاً). التفصيل في [سجل الأعمال](docs/roadmap/05-work-log.md) مُدخلة `WL-003`.
- **الوارد على M2:** خطوة `M2.00` تسبق كل شيء — **239 خطأ نوعياً** في الكود القائم ظهرت حين صار فحص الأنواع يفحص شيئاً فعلاً. الفحص الصارم متاح بـ`npm run typecheck:strict`.
- **ما يعمل فعلاً:** نواة سيادية محلية في `src/` (جذر ثقة بـ Ed25519، بوابة تاج، سجل أحداث بسلسلة تجزئة، نواة تنفيذ، سجلات وكلاء ونماذج وبيانات، قانون ومحكمة) + **مُحمّل سجلات الدولة** `src/registry/loader.mjs` يقرأ البذرة ويتحقق من ترابطها — و**50 اختباراً ناجحاً**.
- **ما لا يعمل:** آلاف الملفات القالبية (‏TypeScript وYAML وSQL) بلا منطق ولا قارئ. **عدد الملفات ليس مؤشر تقدّم.**
- **فجوات حرجة مفتوحة:** لا مخزن أسرار، لا استمرارية بعد إعادة التشغيل، لا مراقبة، لا واجهة، و`main` غير محمي، و239 خطأ نوعياً. **أُغلقت في M0:** التكامل المستمر، وبناء TypeScript، وفحص الأسرار. **أُغلقت في M1:** انتفاخ القوالب، ومصدر حقيقة بنية الدولة، وحواجز الارتداد.

## التشغيل

```bash
nvm use                # يقرأ .nvmrc ⇒ Node 20
npm ci                 # تثبيت من القفل وحده، لا من النطاقات
npm run validate       # البوابة كاملة: lint ← format ← types ← secrets ← tests
```

أوامر مفردة عند الحاجة:

```bash
npm test               # 50 اختباراً
npm run typecheck      # tsc --noEmit
npm run lint           # eslint .
npm run format:check   # prettier --check .
npm run scan:secrets   # فاحص الأسرار — يفشل عند أي مفتاح أو توكن
npm run validate:tree  # التحقق من اكتمال شجرة المجالات
```

**لا يُدفع شيء و`npm run validate` أحمر.** ونفس الفحوص تجري آلياً على كل دفع وكل طلب دمج عبر [مسار التكامل المستمر](.github/workflows/ci.yml).
