# الدولة الملكية الفدرالية الرقمية

منظومة برمجية سيادية تُنشئ وتُدير عالماً رقمياً مأهولاً بوكلاء ذكاء اصطناعي ونماذج، ينتظمون في مؤسسات وأقاليم وولايات وبلديات، تحكمهم قوانين وسياسات قابلة للتنفيذ الآلي، ويُقيَّد كل قرار مؤثر ببوابة سلطة واحدة (**التاج**) تخضع لإنسان واحد (**الملك**)، مع سجل تدقيق غير قابل للعبث وإمكانية إيقاف شامل في أي لحظة.

   و**اكتشافٌ**. فمن فحصَ ولم يجدْ عيباً قيَّدَ فحصَه وحكمَه، ومن اكتشفَ عيباً ولم
   يُصلِحْه قيَّدَه **ديناً في السجلِّ**. و**كلُّ دفعةٍ إلى المستودعِ تُوثَّقُ**
   بمُدخلةٍ في [سجلِّ الأعمالِ](docs/roadmap/05-work-log.md) بقالبِ المادة 6.
3. **ما لا تملِكُ إغلاقَه لا تُغلِقْه بادّعاءٍ** — يُرفَعُ إلى المالكِ في §6 من سجلِّ
   الديونِ مع **ما هو الدَينُ وكيفَ يُغلَقُ**.
4. **والعملُ غيرُ الموثَّقِ يُعَدُّ كأنّه لم يقعْ** ويُردَّ (المادة 1 من

> [سجلِّ الديونِ](docs/roadmap/06-debt-register.md): أرقامُه (‏≈26% · 311 اختباراً ·
> الخطوة `M2.00`) **أرقامُ 23 أغسطس 2026**، والمقيسُ اليومَ (2026-09-15، `eb61cb44`،
> `npm run validate` برمزِ خروجٍ 0): **1808 اختباراً · 1687 ناجحاً · 0 مخفِقاً ·
> 121 متخطَّى**. والحالُ المعتمدُ في [حالةِ المشروعِ](PROJECT_STATUS.md)
> و[خارطةِ الطريقِ](docs/roadmap/03-roadmap-to-100.md) لا هنا. **ولم يُحرَّرْ نصُّه في
> هذه الدفعةِ قصداً:** تحريرُه إغلاقُ دَينٍ له مُدخلةُ سجلٍّ مستقلّةٌ، والإعلانُ أمانةٌ
> أولى من التجميلِ.

- **نسبة الإنجاز:** ‏≈26% من تعريف الـ100% (خط الأساس كان ≈4%). الحساب وسجل التحديثات في [تدقيق خط الأساس §2.9](docs/roadmap/02-baseline-audit.md).
- **المرحلة الحالية:** المسار **M2 — جذر الثقة الإنتاجي**: خطوة `M2.00` منجزة ومُختبرة (خطوة من 11). قبله المسار **M1 — تصفية الحقيقة** مُغلق ‏8 من 8 و**البوابة G1 مفتوحة**: الشجرة صارت بيانات في `seed/`، وحُذف **33,271** ملفاً قالبياً (المستودع: 33,456 → **204** ملفاً). التفصيل في [سجل الأعمال](docs/roadmap/05-work-log.md) مُدخلتا `WL-003` و`WL-004`.
- **الدين النوعي: مُسدَّد.** كانت **240** مخالفة نوعية حقيقية في الكود القائم (‏239 عند حصرها في M1). صُفِّرت كلها في `M2.00` بأنواع JSDoc، **بلا `any` وبلا `@ts-ignore` وبلا تخفيف علم واحد وبلا تغيير سلوك**، ثم فُعِّل `checkJs` في الإعداد الأساسي فصار `npm run typecheck` فحصاً حقيقياً لا نجاحاً كاذباً. المعيار مُلزم في [معيار التوصيف النوعي](docs/TYPING_STANDARD.md) ويحرسه اختبار مستقل.
- **ما يعمل فعلاً:** نواة سيادية محلية في `src/` (جذر ثقة بـ Ed25519، بوابة تاج، سجل أحداث بسلسلة تجزئة، نواة تنفيذ، سجلات وكلاء ونماذج وبيانات، قانون ومحكمة) + **مُحمّل سجلات الدولة** `src/registry/loader.mjs` يقرأ البذرة ويتحقق من ترابطها — و**311 اختباراً ناجحاً**. ونواة جذر الثقة مكتوبة بـ **TypeScript أصلي** (`src/root-of-trust/*.mts`) وتُصرّف بخطوة بناء موصولة بـ`pretest` و`validate` وCI (الخطوة `M2.01`).
- **ما لا يعمل:** آلاف الملفات القالبية (‏TypeScript وYAML وSQL) بلا منطق ولا قارئ. **عدد الملفات ليس مؤشر تقدّم.**
- **فجوات حرجة مفتوحة:** لا مخزن أسرار، لا استمرارية بعد إعادة التشغيل، لا مراقبة، لا واجهة، و`main` غير محمي (‏`M0.06` محجوبة بقيد خارجي). **أُغلقت في M0:** التكامل المستمر، وبناء TypeScript، وفحص الأسرار. **أُغلقت في M1:** انتفاخ القوالب، ومصدر حقيقة بنية الدولة، وحواجز الارتداد. **أُغلقت في M2.00:** الدين النوعي — صفر خطأ نوعي وفحص صارم مربوط بـCI.

## التشغيل

**من مستودعٍ نظيفٍ إلى نظامٍ عاملٍ بأمرٍ واحد** (‏`M10.05`):

```bash
npm run bootstrap      # الأمر الواحد: مجلَّدات ← تثبيت من القفل ← حاوية القاعدة ← تصريف ← هجرات ← بذرة، ثم فحص صحّة
```

يقرأ العقد المُعلَن في [`config/environment.yaml`](config/environment.yaml)، ويستنبط وضع البيئة، ويُنفِّذ أطواره **بترتيب الوثيقة**، **ويُسمّي كلَّ طورٍ يُتخطّى وسببَه** فلا يُقرأ التخطّي تنفيذاً، ثم ينتهي بحكم فحص صحّة برمز خروجٍ من الوثيقة. وكلُّ طورٍ متكافئ: إعادةُ الأمر نفسِه جوابٌ صحيحٌ لكلّ فشل. وأعلامُه `--dry-run` (يحسب الخطّة ولا يُحدث أثراً) و`--json` و`--profile=<id>`.

ولفحص الصلاح وحدَه — **قراءةٌ محضةٌ لا تُصلح شيئاً**:

```bash
npm run verify:env     # حكم: healthy | degraded | unfit — ورمز الخروج يقرؤه مسار آليّ
```

والتفصيل كلُّه في [عقد البيئة والإقامة بأمر واحد](docs/ENVIRONMENT.md).

وإن أردت الأطوار مفردةً بيدك:

```bash
nvm use                # يقرأ .nvmrc ⇒ Node 20
npm ci                 # تثبيت من القفل وحده، لا من النطاقات
npm run validate       # البوابة كاملة: lint ← format ← types ← secrets ← tests
```

أوامر مفردة عند الحاجة:

```bash
npm test               # 311 اختباراً (يسبقه `pretest` فيبني جذر الثقة)
npm run build          # tsc -p tsconfig.build.json — يُصرّف src/root-of-trust/*.mts إلى .mjs في الموضع
npm run typecheck      # tsc --noEmit
npm run lint           # eslint .
npm run format:check   # prettier --check .
npm run scan:secrets   # فاحص الأسرار — يفشل عند أي مفتاح أو توكن
npm run validate:seed  # التحقق من البذرة وترابطها (كان مكتوباً `validate:tree` ولا وجود له — صُحّح في `WL-005`)
```

**لا يُدفع شيء و`npm run validate` أحمر.** ونفس الفحوص تجري آلياً على كل دفع وكل طلب دمج عبر [مسار التكامل المستمر](.github/workflows/ci.yml).
