ومؤسّساتٍ وأقاليمَ، يُقيَّدُ فيها كلُّ قرارٍ مؤثِّرٍ ببوابةٍ واحدةٍ (**التاج**) تخضعُ لمفتاحِ إنسانٍ
واحدٍ (**الملك**) محفوظٍ في وحدةِ أمانٍ، مع سجلٍّ مختومٍ يكشفُ العبثَ ومفتاحِ إيقافٍ شاملٍ.

## الوضعُ الحاليُّ باختصارٍ

- **ما هو:** مكتبةُ مكوّناتٍ مُختبَرةٌ (‏جذرُ ثقةٍ على PKCS#11، بوابةُ تاجٍ ودفترُ أوامرَ موقَّعٌ،
  سجلٌّ دائمٌ مختومٌ بتثبيتٍ دوريٍّ، بيانُ حالةٍ مختومٌ، وقتٌ مُبرهَنٌ بنصابِ Roughtime، سلسلةُ إنفاذٍ
  بهويّةٍ وسياسةٍ وحَجرٍ، نواةُ تنفيذٍ بوضعٍ آمنٍ، استمراريّةٌ على PostgreSQL، وعشراتُ الوحداتِ
  المحكومةِ بعقودِ `config/*.yaml` وحواجزِ `guard:*`).
- **المسارُ الإنتاجيُّ موصولٌ ويرفضُ الإقلاعَ مغلقاً عمداً:** `scripts/production-entry.mjs` يشترطُ
  مصدرَ حداثةٍ دائماً، **ولا مصدرَ مدعوماً منفَّذٌ** (‏`R3-A-01` / `EXT-6`). فلا نشرَ إنتاجيَّ قائمٌ،
  ولا يصحُّ وصفُ أيِّ جزءٍ بأنّه «جاهزٌ للإنتاجِ».
- **المراجعةُ المستقلّةُ لم تكتملْ:** 23 نتيجةً من 58 مفتوحةٌ في `config/external-review.yaml`،
  و`M11.04`–`M11.06` و`M11.09` و`G11` لم تُغلَقْ. **لا اعتمادَ ولا إطلاقَ ولا «100%».**
- **نسبةُ `version.json`** عدّادُ خطواتِ الخارطةِ المنجَزةِ (‏محسوبٌ آليّاً)، **وليست مقياسَ جاهزيّةٍ
  تشغيليّةٍ**.

## المعماريّةُ المنفَّذةُ

```text
Production Entry (scripts/production-entry.mjs → src/production/entrypoint.mjs)
  → Freshness gate        (يرفضُ غيابَ المقبسِ أو مقبسَ الاختبارِ)
  → Production Root of Trust (src/root-of-trust/production-runtime.mts)
       HSM/PKCS#11 · بيانُ حالةٍ مختومٌ · سجلٌّ مختومٌ · دفترُ أوامرَ · مفتاحُ إيقافٍ · مخزنُ سحبٍ
  → King identity من المفتاحِ العامِّ في HSM
  → Enforcement chain     (هويّةٌ · سياسةٌ · حَجرٌ — src/core/composition-root.mjs)
  → Attested time         (src/time/attested-clock.mjs)
  → Crown gateway         (src/root-of-trust/crown.mts)
  → Execution kernel      (src/core/execution-kernel.mjs — SafeMode)
  → Audit                 (PersistentEventLog مختومٌ)
```

والحدودُ المقروءةُ في الكودِ — إصدارُ الشهاداتِ في الإنتاجِ عبرَ `CertificateAuthority.issueAsync` بموقِّعِ التوكنِ (‏`WL-303`)، و`npm run serve` مسارُ تطويرٍ
يرفضُ الإنتاجَ، وPostgreSQL لا يستعملُها المسارُ الإنتاجيُّ — في §3 من
[الحالةِ الحاليّةِ](docs/CURRENT_STATE.md).

## ما يُثبِتُه CI وما لا يُثبِتُه

CI على `ubuntu-latest` المستضافِ (‏منذ `WL-286`) بحاويةِ `postgres:18.6-alpine`، ويُشغِّلُ
`npm run validate` كاملاً. **وتُتخطّى فيه بأسبابٍ مطبوعةٍ:** اختباراتُ محاكي TPM، وتوكنُ SoftHSM
الحقيقيُّ، والعزلُ بمساحاتِ الأسماءِ (‏`userns` محظورٌ على المضيفِ)، والقنواتُ الحيّةُ. فالأخضرُ يُثبِتُ
المنطقَ والعقودَ والقاعدةَ، **ولا يُثبِتُ** HSM عتاديّاً ولا TPM ولا العزلَ الحقيقيَّ — انظر §6 من
[الحالةِ الحاليّةِ](docs/CURRENT_STATE.md). **وعددُ الاختباراتِ يُقرأُ من مخرَجِ `npm test`** لا من وثيقةٍ.

## التشغيلُ للتطويرِ

```bash
nvm use                # Node 20 من .nvmrc
npm ci                 # من القفلِ وحدَه
npm run bootstrap      # مجلّداتٌ ← تثبيتٌ ← حاويةُ القاعدةِ ← تصريفٌ ← هجراتٌ ← بذرةٌ ← فحصُ صحّةٍ
npm run verify:env     # قراءةٌ محضةٌ: healthy | degraded | unfit
npm run validate       # البوابةُ كاملةً: lint ← format ← types ← secrets ← الحواجزُ ← الاختباراتُ
npm test               # الاختباراتُ وحدَها (بتزامنٍ 1) — اختباراتُ القاعدةِ تحتاجُ DATABASE_URL
```

والتفصيلُ في [عقدِ البيئةِ](docs/ENVIRONMENT.md). **وما هو تطويرٌ أو اختبارٌ فقط:** `npm run serve`،
ومخزنُ المفاتيحِ المحلّيُّ المشفَّرُ، و`InMemoryFreshnessSocket`، وSoftHSM، ومحاكي TPM
(‏`sim/tpm/`)، وعيّناتُ Roughtime المثبَّتةُ (‏`tests/fixtures/roughtime/`).

## متطلّباتُ الإنتاجِ (‏غيرُ مستوفاةٍ اليومَ)

وحدةُ أمانٍ PKCS#11 بمفاتيحِ F05/F06/F07 (‏[`docs/HSM_KEYS.md`](docs/HSM_KEYS.md))، ومصدرُ حداثةٍ
دائمٌ خارجَ القرصِ (‏تصميمُه [ADR 0007](docs/adr/0007-tpm-nv-counter-freshness-anchor-design.md) بلا
تنفيذٍ)، ووصولُ UDP إلى خوادمِ Roughtime المعلَنةِ في `config/time.yaml`، وجذرُ حالةٍ مُجهَّزٌ
(‏`XUUX_STATE_ROOT`).

## الفجواتُ الكبرى

بالحجبِ: مصدرُ الحداثةِ الإنتاجيُّ ← HSM عتاديٌّ ← نتائجُ المراجعةِ المفتوحةُ ← تغطيةُ CI للعزلِ وTPM وHSM
← قرارُ الإطلاقِ. (‏وإلزامُ فحصِ CI ومنعُ الدفعِ القسريِّ على `main` نُفِّذا في `WL-302` ومقيسانِ في `WL-341`؛
وتسجيلُ `M0.06` في اللوحةِ للمالك.) والقائمةُ الحاكمةُ بمن يملكُ كلَّ بندٍ في
[سجلِّ الديونِ](docs/roadmap/06-debt-register.md).
