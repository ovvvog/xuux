   [سجلِّ الديونِ الموحَّدِ](docs/roadmap/06-debt-register.md)، وإمّا **خطوةٌ من
   [خارطةِ الطريقِ الرسميّةِ](docs/roadmap/03-roadmap-to-100.md)** — **ولا يُبدأُ
   بالثاني قبلَ استنفادِ ما يُمكِنُ إغلاقُه من الأوّلِ.**
2. **كلُّ عملٍ يُوثَّقُ — والعملُ ثلاثةٌ:** **دفعٌ** إلى المشروعِ، و**فحصٌ**،
   و**اكتشافٌ**. فمن فحصَ ولم يجدْ عيباً قيَّدَ فحصَه وحكمَه، ومن اكتشفَ عيباً ولم
   يُصلِحْه قيَّدَه **ديناً في السجلِّ**. و**كلُّ دفعةٍ إلى المستودعِ تُوثَّقُ**
   بمُدخلةٍ في [سجلِّ الأعمالِ](docs/roadmap/05-work-log.md) بقالبِ المادة 6.
3. **ما لا تملِكُ إغلاقَه لا تُغلِقْه بادّعاءٍ** — يُرفَعُ إلى المالكِ في §6 من سجلِّ
   الديونِ مع **ما هو الدَينُ وكيفَ يُغلَقُ**.
4. **والعملُ غيرُ الموثَّقِ يُعَدُّ كأنّه لم يقعْ** ويُردَّ (المادة 1 من
   [القاعدةِ الحاكمةِ](GOVERNANCE_RULE.md)).

## الحالة الحقيقية — **لا تُكتَبُ هنا، تُحسَبُ هناك**

**كان هذا القسمُ يحملُ أرقاماً مكتوبةً بيدٍ** («‏≈26%» · «311 اختباراً» · الخطوة `M2.00`)، **فتجمَّدَ على 23 أغسطس 2026** ثلاثةَ أسابيعَ وأحدَ عشرَ مساراً، وواجهةُ المشروعِ أوّلُ ما يقرؤه من يأتي. **فحُذِفت الأرقامُ من هنا ولم تُصحَّحْ:** رقمٌ يُنسَخُ إلى موضعٍ ثانٍ يَنحرِفُ عن الأوّلِ لا محالةَ — وهذا نفسُه الدَينُ `DOC-7`، وقد أُغلِقَ في `WL-172` **بإزالةِ سببِه لا بتحديثِ نسختِه**.

**فمن أرادَ حالَ المشروعِ فمن مصدرِه المحسوبِ وحدَه:**

| ما تريدُ معرفتَه | مصدرُه الواحدُ | كيفَ يُقاسُ |
| --- | --- | --- |
| نسبةُ الإنجازِ وعدّادُ الخطواتِ | [`version.json`](version.json) و[لوحةُ التقدُّمِ](docs/roadmap/03-roadmap-to-100.md) | **محسوبةٌ آلياً** من جدولِ الخطواتِ في `scripts/progress-facts.mjs`، **ولا تُقدَّرُ تقديراً** (المادة 8). و`npm run guard:progress` يرفضُ انحرافَ المواضعِ الأربعةِ عن بعضِها |
| المسارُ والخطوةُ الحاليّةُ وما جرى آخِراً | [`PROJECT_STATUS.md`](PROJECT_STATUS.md) | و`npm run guard:status-freshness` يرفضُ أن تتجمَّدَ عن [سجلِّ الأعمالِ](docs/roadmap/05-work-log.md) |
| عددُ الاختباراتِ وحكمُ البوابةِ | `npm run validate` على جهازِك | **رقمٌ يُشغَّلُ لا رقمٌ يُقرأُ:** لا يُنقَلُ إلى وثيقةٍ لأنّه يتغيّرُ بكلِّ دفعةٍ |
| ما هو مفتوحٌ ومَن يملِكُ إغلاقَه | [سجلُّ الديونِ الموحَّدُ](docs/roadmap/06-debt-register.md) | §4 بنداً بنداً، و§6 ما لا يملِكُ المنفِّذُ إغلاقَه |
| جاهزيّةُ البنودِ ودليلُ كلِّ بندٍ | `npm run readiness:report` | **تغطيةٌ مقيسةٌ لا اعتمادٌ:** لا مراجعةً مستقلّةً ولا `G11` ولا إطلاقاً ولا «100%» |

**وما يبقى صحيحاً هنا بلا رقمٍ يَنحرِفُ:**

- **ما يعملُ فعلاً:** نواةٌ سياديّةٌ في `src/` تُشغَّلُ وتُختبَرُ — جذرُ ثقةٍ، وبوابةُ تاجٍ، وسجلُّ أحداثٍ بسلسلةِ تجزئةٍ، ومحرِّكُ سياساتٍ، ومُوائمُ استدلالٍ، وإنفاذٌ بجذرِ تركيبٍ واحدٍ، ودوامٌ على `PostgreSQL` حقيقيٍّ.
- **ما لا يعملُ:** آلافُ الملفّاتِ القالبيّةِ (‏`TypeScript` و`YAML` و`SQL`) بلا منطقٍ ولا قارئٍ. **وعددُ الملفّاتِ ليس مؤشِّرَ إنجازٍ**، ولذلك يُقاسُ بحاجزٍ (`npm run guard:templates`) لا يُفتخَرُ به.
- **وما لم يُعتمَدْ بعدُ:** **لا مراجعةَ مستقلّةً نهائيّةً، ولا `G11` مفتوحةً، ولا «100%»، ولا إطلاقَ.** ومن قرأَ في هذا المستودعِ ما يخالفُ هذا السطرَ فقد قرأَ دعوىً تُقيَّدُ ديناً.

## التشغيل

**من مستودعٍ نظيفٍ إلى نظامٍ عاملٍ بأمرٍ واحد** (‏`M10.05`):

```bash
npm run bootstrap      # الأمر الواحد: مجلَّدات ← تثبيت من القفل ← حاوية القاعدة ← تصريف ← هجرات ← بذرة، ثم فحص صحّة
```

يقرأ العقد المُعلَن في [`config/environment.yaml`](config/environment.yaml)، ويستنبط وضع البيئة، ويُنفِّذ أطواره **بترتيب الوثيقة**، **ويُسمّي كلَّ طورٍ يُتخطّى وسببَه** فلا يُقرأ التخطّي تنفيذاً، ثم ينتهي بحكم فحص صحّة برمز خروجٍ من الوثيقة. وكلُّ طورٍ متكافئ: إعادةُ الأمر نفسِه جوابٌ صحيحٌ لكلّ فشل. وأعلامُه `--dry-run` (يحسب الخطّة ولا يُحدث أثراً) و`--json` و`--profile=<id>`.

ولفحص الصلاح وحدَه — **قراءةٌ محضةٌ لا تُصلح شيئاً**:

```bash
npm run verify:env     # حكم: healthy | degraded | unfit — ورمز الخروج يقرؤه مسار آليّ
```

والتفصيل كلُّه في [عقد البيئة والإقامة بأمر واحد](docs/ENVIRONMENT.md).

وإن أردت الأطوار مفردةً بيدك:

```bash
nvm use                # يقرأ .nvmrc ⇒ Node 20
npm ci                 # تثبيت من القفل وحده، لا من النطاقات
npm run validate       # البوابة كاملة: lint ← format ← types ← secrets ← tests
```

أوامر مفردة عند الحاجة:

```bash
npm test               # مجموعةُ الاختباراتِ كلُّها (يسبقه `pretest` فيبني جذر الثقة). **العددُ يُقرأُ من مخرَجِه لا من هذا السطرِ**
npm run build          # tsc -p tsconfig.build.json — يُصرّف src/root-of-trust/*.mts إلى .mjs في الموضع
npm run typecheck      # tsc --noEmit
npm run lint           # eslint .
npm run format:check   # prettier --check .
npm run scan:secrets   # فاحص الأسرار — يفشل عند أي مفتاح أو توكن
npm run validate:seed  # التحقق من البذرة وترابطها (كان مكتوباً `validate:tree` ولا وجود له — صُحّح في `WL-005`)
```

**لا يُدفع شيء و`npm run validate` أحمر.** ونفس الفحوص تجري آلياً على كل دفع وكل طلب دمج عبر [مسار التكامل المستمر](.github/workflows/ci.yml).
