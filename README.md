# الدولة الملكية الفدرالية الرقمية

منظومة برمجية سيادية تُنشئ وتُدير عالماً رقمياً مأهولاً بوكلاء ذكاء اصطناعي ونماذج، ينتظمون في مؤسسات وأقاليم وولايات وبلديات، تحكمهم قوانين وسياسات قابلة للتنفيذ الآلي، ويُقيَّد كل قرار مؤثر ببوابة سلطة واحدة (**التاج**) تخضع لإنسان واحد (**الملك**)، مع سجل تدقيق غير قابل للعبث وإمكانية إيقاف شامل في أي لحظة.

## الحالة الحقيقية (محقَّقة في 2026-08-23)

- **نسبة الإنجاز:** ‏≈4% من تعريف الـ100%. الحساب في [تدقيق خط الأساس §2.9](docs/roadmap/02-baseline-audit.md).
- **ما يعمل فعلاً:** نواة سيادية محلية في `src/` (جذر ثقة بـ Ed25519، بوابة تاج، سجل أحداث بسلسلة تجزئة، نواة تنفيذ، سجلات وكلاء ونماذج وبيانات، قانون ومحكمة) — و**27 اختباراً ناجحاً**.
- **ما لا يعمل:** آلاف الملفات القالبية (‏TypeScript وYAML وSQL) بلا منطق ولا قارئ. **عدد الملفات ليس مؤشر تقدّم.**
- **فجوات حرجة مفتوحة:** لا مخزن أسرار، لا استمرارية بعد إعادة التشغيل، لا تكامل مستمر، لا بناء لـ TypeScript، لا مراقبة، لا واجهة.

## التشغيل

```bash
node --version                    # يجب أن يكون 20.x
node --test tests/*/*.test.mjs    # خط الأساس: 27 اختباراً ناجحاً
python3 scripts/validate-tree.py  # التحقق من اكتمال شجرة المجالات
```

لا توجد تبعيات خارجية حالياً، ولا خطوة بناء. إنشاؤهما هو المسار **M0** في خارطة الطريق، وهو **نقطة البداية الإلزامية** لأي عمل قادم.
