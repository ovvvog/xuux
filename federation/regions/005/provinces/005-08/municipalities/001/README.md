# بلدية الإقليم 005 الولاية 08 المجتمع 01

النوع: بلدية ومجتمع محلي.
الغرض: تشغيل خدمات المستوى المحلي وربطها بالولاية والإقليم.
النطاق: السكان، الخدمات، الموارد، المرافق، الاتصالات، السلامة، والتدقيق.
الحدود: لا يتجاوز التفويض المحلي ولا ينشئ قناة سيادية مستقلة.
الحالة: تعريف تأسيسي قابل للتوسع والاختبار.
