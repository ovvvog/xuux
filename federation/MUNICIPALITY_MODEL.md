# نموذج البلدية والمجتمع

البلدية هي وحدة تنفيذ محلية تدير الخدمات والمرافق ضمن تفويض الولاية.
تسجل السكان والوكلاء والموارد والمهام، وترفع الاستثناءات عبر الولاية والإقليم.
لا تنشئ البلدية سياسة سيادية، ولا تتعاقد خارجيًا، ولا تغير هوية الوكلاء دون اعتماد.
كل خدمة لها مالك وميزانية ومؤشر وسجل تدقيق وخطة تعافٍ.
