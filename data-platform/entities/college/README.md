# college

النوع: سجل بيانات سيادي أو تشغيلي.
الغرض: تعريف دورة حياة البيانات والواجهات والضوابط التشغيلية لهذا الكيان.
النطاق: المخطط، الوصول، الجودة، الاحتفاظ، النسخ، التدقيق، والاستعادة.
الحماية: تصنيف وشفافية وأقل امتياز ومنع التسريب أو التعديل غير المصرح.
الحالة: عقد تأسيسي قبل ربطه بمحرك التشغيل.
